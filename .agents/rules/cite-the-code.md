# Cite the Code Rule

When writing explanations, answering user queries, or documenting modifications in the Job Decision Engine project:

1. **Specific File References**: Always refer to precise absolute or relative file paths (e.g., `/server.ts` or `/src/db/db.ts`).
2. **Line Number Citation**: Reference specific lines or block coordinates within the file to anchor explanations in the physical code.
3. **No Placeholders**: Avoid talking about components or endpoints in the abstract. Always trace them to their actual coordinates in the workspace.
